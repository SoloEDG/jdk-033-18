## 缩帆 / 绞盘

右舷仪表新增“缩帆与绞盘”面板：

- **同一个绞盘**：帆角滑块/方向键对应调帆角；“收缩帆绳”会把绞盘切到缩帆绳。
- **空程、受力与卡住**：缩帆绳初始有 34% 空程，先收空程；过紧或满缩帆时可能卡住，需要转舵降低负载或放开绞盘。
- **锁定与滑回**：每 8% 缩帆面积有一档机械锁定。放开绞盘后，已锁定面积不退回；尚未锁定的 `reefDraw - reefLocked` 会按帆负载、帆角越界量和反向阵风滑回。
- **帆角维持范围**：仪表实时显示当前风况和负载下可维持缩帆的帆角区间；当前帆角越界时会提示未锁定部分将退回。
- **门线预测**：按当前舵角、绞盘和缩帆状态向前推演 18 秒，显示到达门线延长线的时间、横距、余量，以及继续当前操作是否会偏出门线。
- **计分与回放**：滑回冲击会直接降低船速并反映到冲线时间；缩帆状态随 Sample 保存，航行记录回放、拖动播放头和船帆图形都会恢复当时的锁定面积与退回量。

可点击“布置验证航段”直接到终点线前，然后按：

1. “收缩帆绳”收到至少一档锁定；
2. “停绞”后用左/右舵转舵卸力；
3. 舵回中并点击“恢复收绳 / 再锁一档”；
4. 立即点击风况面板的“制造反向阵风”；
5. 点击“放开绞盘”。
